# 재무행정론 웹교재

정부예산의 개념, 구조, 과정, 이론을 다루는 행정학과 학부 교재. 재정의 기초(희소성·배분·기능)에서 한국 재정의 구조(회계·기금, 통합재정, 과목체계, 예산의 종류), 재정정책(확장정책·재정준칙·통화정책), 재정과정(편성·심의·집행·결산)과 예산행태·예산이론, 재정분석(비용편익분석·예비타당성조사)과 재정개혁·평가까지. 15주 학기 기준 8주차 중간고사·15주차 기말고사를 제외한 13개 콘텐츠 주차(1-7·9-14주) × 주당 2차시 = 총 26개 장. 형식은 「디지털 시대의 행정」·「텍스트로 보는 행정사」 웹교재를 계승한다.

## 웹교재 (HTML)

Kwangwoon University 강의 교재 웹사이트로 빌드되어 있으며, GitHub Pages로 게시된다: https://hoor0015.github.io/public-finance-textbook/ (main에 푸시하면 자동 재배포). 본문(md)을 고친 뒤 `code/build_html.py`를 실행하면 다시 빌드된다.

## 원자료와 집필 방식

- 원자료: `_sources/ppt/`(강의 슬라이드 17종 텍스트, 02-17번 덱이 본문의 골격).
- 강의 덱은 기획재정부 시절에 제작되어, 2026년 정부조직 개편(기획재정부 → 기획예산처·재정경제부 분리)과 국가재정법 등 법 개정 사항을 웹 검색으로 검증해 전 장에 반영했다. 검증 결과는 `_sources/research/법제도브리프_2026.md`에 출처와 함께 정리되어 있다.
- 재정 수치(총지출, 국가채무, 통합재정수지 등)는 2026년 본예산 기준으로 갱신하고 연도 기준을 본문에 명시했다.
- 덱의 이론 체계와 학술 인용(Key, Wildavsky, Schick, Rubin, Kingdon 등)은 교재의 골격으로 유지했다.
